LosslessCut goes in this folder.

Video review (Annotate, Export animations, Misclassification analysis)
opens video clips in LosslessCut. It isn't included with StrikeWorks
because of its size (about 900 MB).

To add it:
  1. Download the Windows (x64) portable version of LosslessCut from
     https://github.com/mifi/lossless-cut/releases
  2. Extract it.
  3. Copy everything it contains - LosslessCut.exe and all the files and
     folders beside it - into this folder, so that LosslessCut.exe sits
     directly in this folder, next to this readme.

No restart or setting is needed; the video buttons find it here.
